# Exteros' Tweaks

A standalone mod by Exteros, needs only [Exteros' Lib](https://mods.factorio.com/mod/exteros-lib) (installed automatically). Holds small balance-adjacent tweaks that still change the game's numbers.

[![Factorio 2.1](https://img.shields.io/badge/Factorio-2.1-orange.svg)](https://mods.factorio.com/mod/Exteros-QoL-Tweaks) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## Features

Each feature has its own startup switch. Nothing changes until you turn it on.

⚠️ **Fuel Stats** - Changes the energy value, vehicle acceleration and top speed of every vanilla and Space Age fuel.

⚠️ **Recycler Return Rate** - Sets how much the recycler gives back, 1-100% (vanilla 25%), either only for items that recycle into themselves (default) or for every recipe except scrap. Handy for quality upcycling loops.

⚠️ **Roboports** - Makes charging station counts scale with quality, like robot and material slots already do, and lets you multiply charging speed. Stacks on top of vanilla quality's own speed bonus.

Fuel Stats and Recycler Return Rate replace my earlier standalone mods Adjustable Fuel Stats and Adjustable Recycler, now relicensed MIT. If one of those is still installed, the matching feature here stays hidden; remove the old mod to use it here.

## Other Mods

⚙️ **[Exteros' QoL](https://mods.factorio.com/mod/Exteros-QoL-System)** - Rate Calculator, Even Distribution, Belt Brush, Ghost Builder and many more quality of life features, each switched on separately.

🧪 **[Exteros' Cheats](https://mods.factorio.com/mod/Exteros-QoL-Cheats)** - Reach, crafting and mining speed, inventory slots, stack sizes, productivity on every recipe, and roboport range.

## Installation

Install through the in-game mod manager, or from the [Factorio Mod Portal](https://mods.factorio.com/mod/Exteros-QoL-Tweaks). Exteros' Lib is installed with it; Exteros' QoL is not required.

## Compatibility

- **Factorio 2.1** only - the 2.0 line is no longer supported from 1.0 on.
- **Space Age** and **Quality** - supported.
- **Other mods** - Fuel Stats and Recycler Return Rate switch themselves off when Adjustable Fuel Stats or Adjustable Recycler is installed.
- **Missing a mod?** If one does the same thing as a feature here and both run at once, please [open an issue](https://github.com/pabienko/Exteros-QoL-Tweaks/issues) with its name.
